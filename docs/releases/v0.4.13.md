## 修正

同時開著多個 Zipo（多個視窗，或同時使用命令列）時：

- **壓縮檔可能損壞**：兩個 Zipo 同時壓縮或更新同一個壓縮檔時，會互相寫壞。現在後開始的會提示「另一個 Zipo 正在寫入」，等前一個完成後再試即可。
- **記憶體不足而當掉**：兩個 Zipo 同時以高壓縮等級建立 7z 或 xz 時，合計會用掉太多記憶體。現在後開始的會等前一個完成（顯示「等待其他 Zipo 的壓縮工作完成…」，可以取消）；小檔案與解壓縮不受影響。
- **設定被改回去**：關閉視窗時，會把其他視窗剛改過的設定（例如語言、自動更新）改回舊值。現在只儲存這個視窗改過的設定。
- **跨視窗拖曳沒有反應**：從一個 Zipo 視窗把壓縮檔內的項目拖到另一個 Zipo 視窗，現在可以直接加入。

其他：

- **線上更新不再只更新一半**：圖形介面已換成新版、命令列卻更新失敗時，會把圖形介面也還原，不會兩邊版本不一致。上次更新前開啟的 Zipo 視窗還沒關而無法更新時，會說明原因（原本顯示「沒有權限」）。這項改進從下一次更新開始生效。
- 英文介面在壓縮檔中，搜尋框的提示文字被截斷；「包含子資料夾」改為顯示在滑鼠提示中。

## 更新方式

- 使用 0.3.0 以後的版本，Zipo 啟動時會提示更新（或在「⋯」選單點「檢查更新…」）
- 使用 0.2.x 的話，請手動下載下方的 zip

## 下載

**Windows 64 位元**：下載 `zipo-0.4.13-windows-x64.zip`，解壓縮後即可使用，不需要安裝。

| 檔案 | 用途 |
|---|---|
| `zipo-gui.exe` | 圖形介面（檔案管理員） |
| `zipo.exe` | 命令列，指令語法與 7-Zip 的 `7z.exe` 相同 |

> 這個版本沒有數位簽章，第一次執行時 Windows SmartScreen 可能會顯示警告，請點「其他資訊 › 仍要執行」。
