## 改進

- **網址列旁新增「選擇資料夾」按鈕**（📂）：點了開啟 Windows 的選擇資料夾視窗，從目前所在的資料夾開始，選好就切換過去。原本網址列只能直接輸入路徑。

## 更新方式

- 使用 0.3.0 以後的版本，Zipo 啟動時會提示更新（或在「⋯」選單點「檢查更新…」）
- 使用 0.2.x 的話，請手動下載下方的 zip

## 下載

**Windows 64 位元**：下載 `zipo-0.4.7-windows-x64.zip`，解壓縮後即可使用，不需要安裝。

| 檔案 | 用途 |
|---|---|
| `zipo-gui.exe` | 圖形介面（檔案管理員） |
| `zipo.exe` | 命令列，指令語法與 7-Zip 的 `7z.exe` 相同 |

> 這個版本沒有數位簽章，第一次執行時 Windows SmartScreen 可能會顯示警告，請點「其他資訊 › 仍要執行」。
