## 更容易使用

- **預設壓縮格式改為 zip**：Windows、macOS 不必安裝軟體就能開啟；從舊版更新也會改為 zip，之後選的格式會記住。
- **「壓縮」對話框重新整理**：常用項目在前；格式旁附一句說明；勾選「設定密碼」才顯示密碼欄；分割大小等少用的選項收進「更多選項」。
- **「解壓縮」對話框改用白話**：「保留資料夾結構／所有檔案放在同一層」「目的地已有同名檔案時：每次詢問、取代、略過並保留原有的檔案、兩者都保留」，收進「更多選項」。
- **按鈕寫出動作**：「壓縮」「解壓縮」「解鎖」，不再都是「確定」。
- **長路徑、長檔名從中間省略**，保留檔名；滑過時顯示完整內容。
- **錯誤訊息說明下一步怎麼做**：例如檔案損壞時建議重新下載、空間不足時建議清出空間或改存到其他磁碟。
- **對話框超過視窗高度時可以捲動**。
- 右鍵選單改為「用 Zipo 壓縮…」（更新後啟動一次會自動換成新名稱）。

## 新的快捷鍵（與檔案總管相同）

| 操作 | 按鍵 |
|---|---|
| 複製到剪貼簿（可在檔案總管貼上） | Ctrl+C |
| 把剪貼簿上的檔案加入開啟中的壓縮檔 | Ctrl+V |
| 上一層 | Alt+↑ |
| 延伸選取 | Shift+↑／↓／Home／End |
| 搜尋 | Ctrl+F、F3 |
| 網址列 | Ctrl+L、Alt+D |

對話框按 Tab 時先到主要按鈕。

- 使用 0.2.x 的話，請手動下載下方的 zip

## 下載

**Windows 64 位元**：下載 `zipo-0.4.4-windows-x64.zip`，解壓縮後即可使用，不需要安裝。

| 檔案 | 用途 |
|---|---|
| `zipo-gui.exe` | 圖形介面（檔案管理員） |
| `zipo.exe` | 命令列，指令語法與 7-Zip 的 `7z.exe` 相同 |

> 這個版本沒有數位簽章，第一次執行時 Windows SmartScreen 可能會顯示警告，請點「其他資訊 › 仍要執行」。
