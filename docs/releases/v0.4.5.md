## 改進

- **從右鍵選單啟動時，清單中會選取這次處理的檔案**：「用 Zipo 壓縮」「解壓縮到這裡」「解壓縮到資料夾」開啟時，背後的清單會選取並捲動到這些檔案，與檔案總管相同。
- **「壓縮」對話框顯示項目數與總大小**：例如「要壓縮：a.jpg、b.jpg、申請書.pdf（3 個項目，共 8.2 MB）」；資料夾含所有內容，在背景計算。
- **視窗標題顯示目前位置**：例如「下載 - Zipo」，開了多個視窗時在工作列上好分辨。

## 更新方式

- 使用 0.3.0 以後的版本，Zipo 啟動時會提示更新（或在「⋯」選單點「檢查更新…」）
- 使用 0.2.x 的話，請手動下載下方的 zip

## 下載

**Windows 64 位元**：下載 `zipo-0.4.5-windows-x64.zip`，解壓縮後即可使用，不需要安裝。

| 檔案 | 用途 |
|---|---|
| `zipo-gui.exe` | 圖形介面（檔案管理員） |
| `zipo.exe` | 命令列，指令語法與 7-Zip 的 `7z.exe` 相同 |

> 這個版本沒有數位簽章，第一次執行時 Windows SmartScreen 可能會顯示警告，請點「其他資訊 › 仍要執行」。
