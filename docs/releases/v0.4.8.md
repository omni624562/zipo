## 改進

- **在資料夾中也可以刪除檔案**：選取檔案或資料夾後按 Delete、工具列「刪除」或右鍵「刪除」，與檔案總管相同會移到資源回收筒，可以還原。
  - 無法使用資源回收筒的位置（網路磁碟、部分隨身碟）會由 Windows 先警告
  - 磁碟機不能刪除；壓縮檔內的刪除維持原本的確認流程

## 更新方式

- 使用 0.3.0 以後的版本，Zipo 啟動時會提示更新（或在「⋯」選單點「檢查更新…」）
- 使用 0.2.x 的話，請手動下載下方的 zip

## 下載

**Windows 64 位元**：下載 `zipo-0.4.8-windows-x64.zip`，解壓縮後即可使用，不需要安裝。

| 檔案 | 用途 |
|---|---|
| `zipo-gui.exe` | 圖形介面（檔案管理員） |
| `zipo.exe` | 命令列，指令語法與 7-Zip 的 `7z.exe` 相同 |

> 這個版本沒有數位簽章，第一次執行時 Windows SmartScreen 可能會顯示警告，請點「其他資訊 › 仍要執行」。
