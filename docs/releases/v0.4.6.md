## 改進

- **「⋯」與「檢視」選單改為 Windows 11 樣式**：圖示與 ✓ 對齊在同一欄、快捷鍵靠右；不再混用勾選框與單選圓圈。
  - 「⋯」選單分組，較少用的「檔案總管整合」與「語言 / Language」收進子選單
  - 「檢視」選單的「排序方式」改為子選單；「預覽窗格」等開關以 ✓ 表示開啟
- 工具列按鈕提供名稱給螢幕報讀程式。

## 更新方式

- 使用 0.3.0 以後的版本，Zipo 啟動時會提示更新（或在「⋯」選單點「檢查更新…」）
- 使用 0.2.x 的話，請手動下載下方的 zip

## 下載

**Windows 64 位元**：下載 `zipo-0.4.6-windows-x64.zip`，解壓縮後即可使用，不需要安裝。

| 檔案 | 用途 |
|---|---|
| `zipo-gui.exe` | 圖形介面（檔案管理員） |
| `zipo.exe` | 命令列，指令語法與 7-Zip 的 `7z.exe` 相同 |

> 這個版本沒有數位簽章，第一次執行時 Windows SmartScreen 可能會顯示警告，請點「其他資訊 › 仍要執行」。
