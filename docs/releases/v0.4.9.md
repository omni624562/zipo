## 修正

- **修正點選路徑欄位時可能當掉**：在壓縮或解壓縮對話框點路徑欄位開始編輯時，若電腦上有讀取畫面的程式（螢幕報讀、部分輸入法或桌面工具），Zipo 可能當掉。
- **分割壓縮更可靠**：
  - 分割期間顯示進度與目前寫入的檔名，也可以取消（原本進度停在 100%，看起來像當掉）
  - 分割檔全部寫完才出現，中途中斷不會留下缺檔的分割檔；失敗或取消時不留下任何檔案
  - 完成訊息的「原始大小」顯示正確

## 改進

- **7z 壓縮加快約 25%**：讓所有 CPU 核心都參與壓縮（實測 580 MB：55～59 秒 → 42～45 秒），壓縮檔大小幾乎不變。

## 更新方式

- 使用 0.3.0 以後的版本，Zipo 啟動時會提示更新（或在「⋯」選單點「檢查更新…」）
- 使用 0.2.x 的話，請手動下載下方的 zip

## 下載

**Windows 64 位元**：下載 `zipo-0.4.9-windows-x64.zip`，解壓縮後即可使用，不需要安裝。

| 檔案 | 用途 |
|---|---|
| `zipo-gui.exe` | 圖形介面（檔案管理員） |
| `zipo.exe` | 命令列，指令語法與 7-Zip 的 `7z.exe` 相同 |

> 這個版本沒有數位簽章，第一次執行時 Windows SmartScreen 可能會顯示警告，請點「其他資訊 › 仍要執行」。
