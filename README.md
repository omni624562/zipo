# Zipo

以 [7-Zip](https://www.7-zip.org/) 為藍本、用 Rust 撰寫的壓縮與解壓縮工具，提供圖形介面與命令列兩種用法。

## 功能

- **支援格式**：ZIP、7z、TAR 系列（tar、tar.gz、tar.bz2、tar.xz、tar.zst），以及 gz、bz2、xz、zst 單檔壓縮
- **ISO 映像檔**：瀏覽與解壓縮（ISO 9660、Joliet 中文檔名）；只使用 UDF 的映像檔（例如 Windows 安裝光碟）目前不支援
- **密碼加密**：ZIP 與 7z 採用 AES-256；7z 可連檔名一起加密
- **分割壓縮**：切成 `名稱.001`、`名稱.002`…（與 7-Zip 相同，可互通），開啟 `.001` 即可瀏覽與解壓縮
- **壓縮等級**：0（僅儲存）到 9（最高壓縮），多核心平行壓縮
- **瀏覽與管理**：直接瀏覽壓縮檔內容，可加入、刪除、更新項目，以及測試完整性；在壓縮檔內搜尋會找遍所有子資料夾
- **安全的解壓縮**：
  - 防止路徑穿越（Zip Slip）與不合法的 Windows 檔名
  - 偵測異常高壓縮比的壓縮炸彈，事先檢查磁碟可用空間
  - 寫入中途失敗不會留下不完整的檔案
  - 保留「從網際網路下載」的安全標記（Mark of the Web）
- **Windows 整合**：
  - 檔案總管右鍵選單：用 Zipo 壓縮、解壓縮到這裡、解壓縮到同名資料夾、解壓縮到資料夾…（選取多個檔案時合併成一個壓縮檔或一次解壓縮）
  - 可設為壓縮檔的預設開啟程式
  - 資料夾名稱與檔案總管一致，顯示中文（文件、下載、桌面…）
- **舊式 ZIP 中文檔名**：自動處理 Big5 等非 UTF-8 編碼的檔名
- **完成後的動作**：壓縮後將原始檔移到資源回收筒（先確認壓縮檔完整）、解壓後將壓縮檔移到資源回收筒、完成後開啟資料夾
- **計算雜湊值**：右鍵「計算雜湊值」或命令列 `zipo h`，同時計算 CRC32、MD5、SHA-1、SHA-256，並可貼上網站提供的值直接比對
- **繁體中文／英文介面**：預設依系統語言，可在「⋯ › 語言 / Language」切換；命令列可用環境變數 `ZIPO_LANG=zh` 或 `en` 指定
- **線上更新**：啟動時自動檢查 GitHub 上的新版本（每天最多一次，可關閉），確認後下載、驗證 SHA-256 並自動重新啟動

## 圖形介面

執行 `zipo-gui.exe`。介面參考 7-Zip 檔案管理員，可以像檔案總管一樣瀏覽資料夾，並直接進入壓縮檔內部。

- 選取檔案後按「壓縮」，選取壓縮檔後按「解壓縮」
- 在壓縮檔內開啟檔案、修改並儲存後，Zipo 會詢問是否存回壓縮檔
- 壓縮檔裡的壓縮檔可以直接點兩下進入瀏覽（唯讀，可解壓縮、預覽、計算雜湊值）
- 「檢視 › 預覽窗格」（Alt+P）：在右側預覽選取的圖片（PNG、JPG、GIF、BMP、WebP）或文字檔，壓縮檔內的檔案也能直接預覽
- 可以把檔案拖曳到視窗中加入壓縮檔；也可以把壓縮檔內的項目直接拖曳到檔案總管或桌面（超過 256 MB 時先在背景解壓縮，完成後再拖曳一次）
- Ctrl+C 把選取的項目複製到剪貼簿（可在檔案總管貼上）；在開啟的壓縮檔內按 Ctrl+V 加入剪貼簿上的檔案
- 在開啟的壓縮檔內按 F2（或右鍵「重新命名」）直接改名，不必解壓縮再重新壓縮
- 刪除（Delete）：在資料夾中與檔案總管相同，移到資源回收筒；在壓縮檔內從壓縮檔刪除（會先確認）
- 快捷鍵與檔案總管相同：Alt+↑ 上一層、Ctrl+F 搜尋、Ctrl+L 網址列、Shift+方向鍵延伸選取等（見 [docs/UX.md](docs/UX.md)）
- 右上角「⋯」選單可以加入檔案總管右鍵選單，或設為預設程式（只修改目前使用者的設定，不需要系統管理員權限，隨時可以移除）

## 命令列

指令語法與 7-Zip 的 `7z.exe` 相同：

```
zipo <指令> [<參數>...] <壓縮檔> [<檔案名稱>...]
```

| 指令 | 說明 |
|---|---|
| `a` | 加入到壓縮檔（已存在時加入或取代同名項目） |
| `d` | 從壓縮檔刪除項目 |
| `rn` | 重新命名壓縮檔內的項目（成對的舊名稱、新名稱） |
| `x` | 解壓縮，保留完整路徑 |
| `e` | 解壓縮，不含資料夾結構 |
| `l` | 列出內容 |
| `t` | 測試完整性 |
| `h` | 計算檔案的雜湊值（CRC32、MD5、SHA-1、SHA-256） |
| `i` | 顯示支援的格式 |

常用參數：`-o{資料夾}` 輸出位置、`-p{密碼}` 密碼、`-mx{0-9}` 壓縮等級、`-mhe=on` 加密檔名、`-t{格式}` 指定格式、`-ao{a|s|u}` 同名檔處理、`-v{大小}` 分割（例如 `-v100m`）、`-x[r]!{名稱}`／`-i[r]!{名稱}` 略過或只處理符合的項目（可用萬用字元，加 r 為每一層）、`-r` 萬用字元也搜尋子資料夾、`-y` 全部回答「是」。完整說明請執行 `zipo` 不加任何參數。

```
zipo a backup.7z 文件 照片 -mx9 -p -mhe=on
zipo x backup.7z -oD:\還原
zipo a 專案.7z 專案 -xr!node_modules -xr!*.log
zipo l backup.7z
```

## 隱私權

Zipo 不收集、不傳送任何使用資料。唯一會連上網路的是線上更新：

- 啟動時（每天最多一次）或在「⋯ › 檢查更新…」時，連到 GitHub 的公開 API（`api.github.com`）查詢最新版本；確認更新後才從 GitHub 下載更新檔
- 只附上 Zipo 的版本號（User-Agent），不會傳送檔案、檔名、設定或任何識別資料；GitHub 會如同一般連線一樣看到你的 IP 位址
- 在「⋯」選單取消「啟動時自動檢查更新」即可停用自動檢查

設定只存在你的電腦上（`%APPDATA%\ZipTool`）。

## 程式碼簽章政策

目前的發布檔**沒有數位簽章**，第一次執行時 Windows SmartScreen 可能會顯示警告。

- 發布檔由 [GitHub Actions](.github/workflows/release.yml) 從標籤對應的原始碼建置與打包，不在個人電腦上建置
- 每個發布檔的 SHA-256 由 GitHub 計算並顯示在 Release 頁面；線上更新會比對這個值
- 計畫申請 [SignPath Foundation](https://signpath.org/) 為開源專案提供的免費程式碼簽章

## 建置

需要 [Rust](https://www.rust-lang.org/tools/install)（2024 edition）。

```
cargo build --release
```

執行檔位於 `target/release/`：`zipo-gui.exe`（圖形介面）與 `zipo.exe`（命令列）。執行測試：

```
cargo test --workspace
```
